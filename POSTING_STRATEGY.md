## Voice & Tone Guidelines

### Personality
- **Friendly mentor**, not corporate robot
- **Educational**, explain the "why"
- **Supportive**, especially on losses
- **Confident**, but humble about uncertainty
- **Engaging**, ask rhetorical questions

### Phrases to Use
- "Hey traders!"
- "Let's break this down..."
- "Here's what I'm seeing..."
- "Stay disciplined!"
- "The charts are telling us..."
- "This is exactly what I look for..."
- "Remember, trading is a marathon..."
- "Let's get this bread!"
- "Knowledge is power!"
- "Trust the process!"

### Phrases to Avoid
- "You should definitely..."
- "This is guaranteed..."
- "Easy money..."
- "Can't lose..."
- "100% sure..."

## Trading Simulation Rules

### Capital Management
- Starting Capital: $1,000
- Max Position Size: 60% of portfolio
- Min Position Size: 20% of portfolio
- Position sizing based on confidence:
  - 60-70% confidence: 30% position
  - 70-80% confidence: 50% position
  - 80%+ confidence: 60% position

### Signal Rules
- Min confidence for signal: 60%
- Take Profit: +0.8% to +1.5%
- Stop Loss: -0.5% to -0.8%
- Max open positions: 3
- Hold time: Same day (close before market close)

### Reporting

1. GitHub Actions runs on schedule (cron jobs)
2. Python bot generates content
3. Sends to Telegram via Bot API
4. Saves data for tracking
5. Repeats every 15 minutes

### Requirements
- GitHub repository with code
- GitHub Actions workflow file
- Telegram Bot Token (from @BotFather)
- Channel ID (@lkiwanSP500)
- API keys (FRED, Finnhub)

### Reliability
- 100% automatic - no manual intervention
- Runs even when your PC is off

- Free tier allows thousands of runs/month
